# GHR CRM — V15.10

Correctif de stabilisation issu des retours de recette V15.9.

- **Navigation Entreprises** : la fiche entreprise normalise désormais systématiquement les données avant rendu, afin d’éviter l’écran Next.js « This page couldn’t load » sur des dossiers issus d’anciennes versions.
- **Modales harmonisées** : suppression des micro-labels décoratifs « Contact », « Relance », etc. dans les aperçus ; le contexte reste porté par le titre et le contenu utile.
- **Tâches** : hiérarchie typographique corrigée, marges homogènes, informations échéance/commentaire/contact plus lisibles et actions mieux alignées.
- **Contacts** : aperçu recentré sur le nom, le rôle, les coordonnées, les actions Appeler / WhatsApp / Message et l’aperçu entreprise.
- **Pipeline** : fenêtre opportunité allégée ; nom de l’entreprise + contact en titre, rôle séparé, ville replacée dans les informations utiles.
- **Fiche entreprise** : réduction du décalage vertical au-dessus de « Retour aux entreprises » et sécurisation des anciennes structures de données.
- **Responsive** : les nouvelles grilles de modale repassent proprement en une colonne sur mobile.

Base : V15.9.
