# GHR CRM V13 — Espace délégué simplifié

Cette version concentre l'espace délégué sur 4 entrées :

- Accueil
- Suivi commercial
- Entreprises
- Rendez-vous

Les écrans Contacts, Actions, Adhésions, Paiements et Historique ne polluent plus la navigation du délégué : leurs informations sont regroupées dans la fiche entreprise.

## Fiche entreprise

La fiche passe de 7 onglets à 3 :

1. Résumé
2. Suivi — contacts, actions, historique, notes et documents
3. Adhésions & paiements

Les actions rapides restent accessibles en haut de la fiche.

## Accueil délégué

Le tableau de bord délégué est désormais orienté action :

- prospects chauds
- rendez-vous du jour
- adhésions actives
- renouvellements proches
- actions du jour
- prochains rendez-vous

L'espace administrateur conserve les vues de pilotage détaillées existantes.
