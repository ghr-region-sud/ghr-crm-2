# GHR CRM V15.22

- Suppression de l’indicateur local « Enregistrement… » qui pouvait rester affiché et clignoter ; la synchronisation globale reste la référence.
- Fenêtre « Vérification avant génération » désormais directement éditable : entreprise, contact, adhésion, options et SEPA.
- Les corrections saisies dans le récapitulatif sont enregistrées dans le CRM au moment de la génération.
- Les champs vides restent autorisés : la génération n’est jamais bloquée.
- Le mandat SEPA reste toujours présent sur le bulletin PDF, comme sur le preview officiel validé, même lorsque le règlement choisi est Virement ou Chèque.
- Template PDF conservé sur une page A4 et aligné sur le preview validé.
