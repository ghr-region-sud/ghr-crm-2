# GHR CRM — V15.14

## Correctif UX aperçu Pipeline > Tâches

- Suppression de la fenêtre imbriquée lors de « Ajouter une tâche » depuis l'aperçu d'une opportunité.
- Le formulaire de création de tâche est maintenant intégré directement dans l'onglet **Tâches**, comme le composeur de l'onglet **Notes**.
- Champs disponibles sans quitter l'aperçu : type, objet, date, heure, contact lié et commentaire.
- Après validation, la tâche est ajoutée immédiatement à la liste située sous le formulaire, sans fermer l'aperçu et sans ouvrir un second modal.
- Mise en page responsive : formulaire compact sur desktop, une colonne sur mobile.
